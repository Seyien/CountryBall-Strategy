## Kural

Kod **birebir** taşınır. Hizası, yorumları ve yazım hataları düzeltilmez.
Güzelleştirilmiş bir arşiv, kanıt olmaktan çıkar.

Satır numarası verilmez. Atıf tip ve üye adıyla yapılır.
